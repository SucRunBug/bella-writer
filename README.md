# bella-writer

一个自媒体内容创作流水线 skill。你给一个主题，它按固定流程把它做成一篇能直接发布的成稿。

## 是什么

不是聊天工具，是一条流水线。七步走：

1. 引导补全创作信息（平台、体量、对标、资料）
2. 强制联网扫各平台实时热榜
3. 诊断内容方向，产出大纲
4. 强制联网核实事实 + 补足背景资料
5. 严格按大纲写作
6. AI 痕迹检测 + 事实核查 + 自我修订
7. 风格归档（把每轮偏好写进个人风格档案）

## 安装

把整个目录放到你的 skill 目录，例如 `.claude/skills/bella-writer/`。

## 用法

触发词 `bella-writer`，或「按 Bella 流程写」「写一篇」「帮我写」「做个内容」「写口播稿」「写公众号」等。

## 目录

- `SKILL.md` —— 主流程（七步）
- `references/` —— 各步骤的作业手册（热点扫描、内容诊断、联网核实、写作、平台规则、AI 检测、个人风格档案）
- `scripts/extract_video.py` —— 抖音对标视频解析（可选）

## 依赖

解析对标视频需要 `scripts/requirements.txt` 里的依赖：

```
pip install -r scripts/requirements.txt
```
